Remote Backup

Remote Backup è un'applicazione per uso esclusivamente personale. Viene utilizzata dal proprietario per salvare backup cifrati del proprio server domestico sul proprio account Google Drive.

Informativa sulla privacy / Privacy policy

L'applicazione accede solo al Google Drive del proprietario, per caricare, leggere ed eliminare i propri file di backup. Nessun dato viene raccolto, condiviso, venduto o trasferito a terzi.

This application is for personal use only. It accesses only the owner's Google Drive to store encrypted backups. No data is collected, shared, sold or transferred to third parties.
